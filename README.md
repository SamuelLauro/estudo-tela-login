# 📚 Estudo: tela de login

Tela de login em HTML, CSS e JavaScript, feita em fevereiro de 2023 para praticar layout de formulários e validação no navegador.

**Demo:** https://samuellauro.github.io/estudo-tela-login/ (use `usuario@exemplo.com` / `senha123`)

## O que faz

- Valida o formato do e-mail antes de conferir as credenciais.
- Mostra mensagens de erro e de sucesso na própria página.

## Observação

É só front-end: as credenciais de demonstração ficam no JavaScript porque não há servidor. Num sistema de verdade, quem valida o login é o back-end, e a senha nunca fica no código do navegador.
